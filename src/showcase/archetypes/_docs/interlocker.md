## Player experience

Interlocker is the archetype where _you don't watch a number, you watch a system_. You start with one raw resource and one activity that produces it. Five minutes in you unlock a building that consumes that resource to produce a second — now you have an input and an output, a _ratio_, and a reason to care about rates. Ten minutes later a third building wants both previous resources at once; now you're balancing. By the time you have four or five buildings feeding each other, you've stopped thinking about any single resource and started thinking about the _graph_ — which node is the bottleneck, which edge is starving, which pair of buildings multiplies each other when placed on the same tech tier.

A thirty-minute session in Interlocker is a sequence of structural moments: _"I finally unlocked Workshop,"_ _"the refinery chain is making plastic,"_ _"I don't have enough wood because my sawmills are feeding the carpentry but nothing is feeding the sawmills."_ The long-term pull is completeness. You feel the shape of the graph fill in — each new tech reveals a new column of buildings, each new building reveals new edges, and the headline moment is not a big number but a wide one: a dashboard with eight resources, all positive per-second rates, all feeding something, no red arrows. There is no compression here; there is weaving.

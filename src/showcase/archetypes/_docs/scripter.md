## Player experience

Scripter is the archetype where _the player is the author of the game's behaviour_. You do not click buttons to advance — you write a program that clicks for you, and progress is the diff between what your script can describe and what the game currently demands of you. The first fifteen minutes are onboarding-via-vocabulary: you learn a tiny command set (`buy`, `wait`, `if`), type a four-line script, hit run, and the screen flashes as a state mutation happens without your hand on the mouse. From that moment, every decision is a rewrite.

A thirty-minute play session is a sequence of edits, runs, and observes. You notice a resource that stalls, edit the script to add a conditional, run it, watch the execution log, tighten the condition, run it again. The long-term pull is _the program plays the game better than you can_ — not a number, not a territory, a proof. End-of-arc is when your script executes a multi-step strategy you could not personally execute by hand inside the arc's time budget. Unlike Looper, the queue is not drag-edited — it is authored in text (or in a spatial command vocab with control-flow constructs) and re-authored when the world demands something the old script cannot name. Unlike Producer, the scaling axis is script quality, not purchase count. The Bitburner player's boast — _"my first script was fifty lines, my hundredth is ten"_ — is the archetype-signature mastery metric.
